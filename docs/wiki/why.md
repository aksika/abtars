# Why abTARS

abTARS is for people who want a personal agent they can run and configure themselves.

## Built around Pi

The API route uses Pi's agent core and provider engine for model requests and tool execution. abTARS adds chat integrations, session handling, tool permissions, scheduled work, and supervised coding runs. The ACP route connects to a compatible agent CLI without using Pi.

## Use it where you already work

Talk to the agent through Telegram or Discord, or connect to the optional local terminal interface. The same abTARS service handles sessions, configuration, and tools across those interfaces.

## Choose integrations

Configure model providers and fallback candidates for the API route, or use an ACP-compatible CLI. Install abmind separately when you want its persistent memory features; it is optional and remains an independent product.

## Operate the service yourself

Configuration and runtime data live on your machine. You choose the interfaces, provider, integrations, and supervision mode. See the [installation](/abtars/install), [transport](/abtars/transport), and [supervision](/abtars/supervision) guides for the current setup.
